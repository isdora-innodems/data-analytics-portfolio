# Data Analytics Portfolio

A collection of beginner-friendly, end-to-end data analytics projects.

## Projects

### 1. AI Usage and Impact on Students and Professionals
Investigating AI adoption, usage patterns, productivity, accuracy, satisfaction, and reported time savings among students and professionals.

Project folder: `AI_Usage_and_Impact_on_Students_and_Professionals/`

Each project contains its own data, notebooks, dashboard, visuals, reports, and documentation.

## Tools
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Power BI (planned for Project 1)
- Git and GitHub

## Important
Check the original dataset's licence and redistribution terms before publishing raw data to a public repository. Cite the dataset source in each project README.
