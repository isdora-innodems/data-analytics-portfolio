# Project Plan

## Working title
AI Adoption and Its Impact on Productivity: An Exploratory Analysis of Students and Professionals

## Main question
How does AI usage differ between students and professionals, and what relationships exist between AI usage and self-reported productivity, satisfaction, accuracy, and time saved?

## Objectives
1. Describe the respondent profile.
2. Compare AI tools and purposes across students and professionals.
3. Summarise daily AI usage and monthly AI cost.
4. Compare self-reported productivity, accuracy, satisfaction, and time saved.
5. Explore associations between usage intensity and reported outcomes.
6. Communicate findings and limitations in an interactive dashboard.

## Important limitations to investigate
- Sample size is 300; representativeness is not established by the supplied description.
- Data appears to be observational and self-reported.
- Monthly income currency is not specified in the supplied description.
- AI_Experience_Years is mentioned in the description but is not a column in the CSV.
- The meaning and scale of Productivity_Score, Accuracy_Rating, and Satisfaction_Score need confirmation.
- Missing values, repeated User_IDs, inconsistent category labels, and text-formatted numeric values require investigation.

## Planned workflow
1. Data understanding and profiling
2. Data quality assessment
3. Data cleaning with documented decisions
4. Exploratory data analysis
5. Comparative and statistical analysis
6. Power BI dashboard
7. Written report and GitHub publication

## Proposed dashboard pages
1. AI Usage Overview
2. User Demographics and Behaviour
3. Productivity and Perceived Impact
4. AI Cost and Reported Value

Dashboard pages and KPIs will be confirmed after data validation.
