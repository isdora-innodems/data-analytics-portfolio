# AI Usage and Impact on Students and Professionals

## Project overview
This project explores how students and professionals use artificial intelligence tools and investigates how AI usage relates to self-reported productivity, accuracy, satisfaction, and time saved.

## Dataset source
Kaggle: https://www.kaggle.com/datasets/eishatuzzuhra/ai-usage-and-impact-on-students-and-professionals

The accompanying dataset description is stored in `data/raw/AboutDataset.txt`.

## Important analytical note
The dataset is observational and appears to contain self-reported measures. Associations must not be described as proof that AI usage causes productivity or time-saving outcomes.

## Data quality
Initial inspection identified missing values, repeated User_ID values, formatting inconsistencies, and numeric columns stored as text. These will be investigated and documented before any records are removed or changed.
